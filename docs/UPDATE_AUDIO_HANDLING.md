# 소리·속도·바퀴 접지·레일 충돌 개선

## 변경 사항

- 기본 속도를 최초 버전의 7.1에서 17.75로 올렸습니다. **150% 상향 = 기존의 2.5배**입니다. ZEPHYR 기준 평지 기본 목표 속도는 계기판 177.5km/h이며, 다른 차량은 기존 속도 계수를 유지합니다.
- 부스트 목표 배율은 2.4, 모든 차량의 실제 속도 상한은 40 world units/초(표시 400km/h)입니다. 내리막에서도 상한을 넘지 않습니다. 코너·충돌·과열 시에는 감속하므로 항상 400km/h로 주행하는 것은 아닙니다.
- 타이어 반지름과 바퀴 중심 높이의 차이, 차량 전체의 추가 높이 오프셋 때문에 떠 보이던 부분을 보정했습니다. 경사·루프에서도 네 바퀴의 높이를 각각 노면에 맞춥니다. 차축을 추가하고 타이어 트레드 방향도 수정했습니다. 그림자 보정값을 줄이고 타이어 바로 아래의 부드러운 접촉 그림자를 추가했습니다.
- 좌우 레일 충돌 시 속도가 즉시 68%로 줄고 안쪽 반동이 생깁니다. 0.42초 동안 가속을 제한하고, 불꽃·충격음·감속 안내·짧은 카메라 흔들림을 표시합니다. 0.65초 대기 시간으로 한 프레임마다 충돌이 반복되지 않게 했습니다. 움직임 감소 설정에서는 흔들리지 않습니다.
- 기본 음소거를 해제하고 기본 음량을 50%로 설정했습니다. 저장된 사용자 음소거·음량은 보존합니다. 상단 소리 버튼에 텍스트를 추가하고, 차고·일시정지 설정에서도 들리는 확인음과 바퀴 테스트 모터음을 추가했습니다.
- 브라우저 오디오 연결을 시작·재개·소리 버튼에서 복구합니다. 실패·미지원·중단 상태를 설정 창에 표시합니다. 음량이 0인 경우 ‘소리 확인’으로 50%까지 복구할 수 있습니다.

오디오 재개는 사용자 클릭/키 입력에서 수행해야 한다는 [Chrome Web Audio 자동재생 정책](https://developer.chrome.com/blog/web-audio-autoplay)을 반영했습니다. 브라우저 탭 자체의 음소거, 시스템 출력 장치·음량까지 게임이 변경하지는 않습니다.

## 검증

- `npm test`: 속도 상향, 400km/h 상한·평지 도달, 내리막 상한, 양쪽 레일 충돌·감속·회복, 접지, 오디오 기본 설정·미지원 처리 등을 포함한 22개 테스트.
- `npm run test:audio`: Chrome의 최종 오디오 출력 경로에서 파형 RMS를 측정합니다. 첫 시작, 일시정지 무음, 오디오 컨텍스트 중단·재개, 설정 확인음, 음량 0 복구, 음소거 저장, 차고 바퀴 테스트, 미지원 안내를 검증합니다.
- `npm run test:contact`: 차량 4종 × 도로 위치 200개 × 타이어 4개, 총 3,200개를 실제 도로 메시와 레이캐스트로 비교합니다. 수직 루프를 포함하며 도로 미검출 0건입니다. 타이어 반지름 기준 간격은 약 -0.0113 ~ +0.0064 world units입니다. 도로 폴리곤과 곡선 표본의 작은 차이를 허용합니다.
- `EVIDENCE_DIR=docs/evidence/audio-handling/regression HEADLESS=1 npm run test:browser`: 차고·3랩 완주·날씨·입력·일시정지·리플레이·10회 재시작·반응형 화면 회귀 검증.
- `npm run build`: 실행 중인 4173 미리보기 서버가 새 빌드를 제공합니다. 페이지를 새로고침하면 적용됩니다. Three.js 청크 크기 경고는 남지만 빌드는 성공합니다.
