# 영상 참고 계기판 적용

사용자가 제공한 약 51초 분량의 레이싱 영상에서 원형 계기판과 화면 배치를 분석해 TABLETOP RACERS에 적용했습니다.

## 적용한 내용

- 반투명 원형 다이얼, 얇은 외곽 테두리, 보라색 270도 게이지.
- 중앙의 밝은 디지털 속도창과 세로 KMH 표기.
- 게임의 실제 속도에 연결된 0~400km/h 눈금과 게이지. 정지·가속·감속 시 함께 갱신됩니다.
- 전기 미니카에 맞춘 EV 표기와 부스트 중 B 표시. 과열·레일 충돌 때는 경고색으로 바뀝니다.
- 넓은 화면에서 열·접지 상태를 다이얼 옆에 배치하고, 좁은 화면에서는 아래에 배치했습니다.
- 가벼운 선 형태의 미니맵, 반투명 순위판과 보라색 순위 강조.
- 리플레이 컨트롤은 계기판 위에 배치했습니다. 움직임 감소 설정도 반영됩니다.

## 확인 결과

- `npm test`: 30개 통과. 기존 방향키 수정과 주행 규칙 포함.
- `npm run test:dashboard`: 9개 검증 그룹 통과.
- 1440×900, 1280×720, 1024×522, 850×700, 390×844에서 화면 밖으로 잘림 없음.
- 실제 키보드 부스트·안정화, 일시정지·재개, 전방 카메라, 오류 없는 로딩 확인.
- 별도의 계기판 컴포넌트 입력으로 0/400 경계, 속도 역순 갱신, 과열·충돌·완주 표시 확인. 이 항목은 실제 레이스 상태를 강제로 변경하지 않는 컴포넌트 검증입니다.
- `npm run build`: 성공. 기존 Three.js 청크 크기 경고는 유지됩니다.

전체 15랩 리플레이를 이번 작업에서 다시 실행하지는 않았습니다. 리플레이의 기존 속도 전달 경로를 사용하며, 역순 데이터 갱신과 컨트롤의 화면 배치를 검사했습니다.
