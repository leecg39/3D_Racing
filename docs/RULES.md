# 게임 규칙과 기술 구조

수치와 차량 프로필의 단일 원본은 [`src/config.js`](../src/config.js)입니다.

## 경주

- 플레이어 1대와 AI 3대, 총 3랩. 진행거리 증가로 자동 전진합니다.
- 매 랩 12개 체크포인트를 순서대로 통과해야 랩을 인정합니다.
- 결승선 통과 시점을 물리 프레임 안에서 보간합니다. 완주자는 통과 시간, 미완주자는 유효 진행거리 순으로 정렬합니다.
- 큰 진행거리 점프와 역주행은 거부합니다. 공간상 가까운 다른 도로로 차량을 이동시키지 않습니다.
- 플레이어가 먼저 완주하면 다른 차량의 결승선 통과 후 최종 결과를 표시합니다.
- AI는 미래 곡률·젖은 구간·열·앞차와 빈 주행선을 보고 부스트와 안정화를 선택합니다. 순간이동이나 순위 보정은 없습니다.

## 입력의 이득과 비용

| 항목 | 규칙 |
|---|---|
| 기본 속도 | 7.1 × 차량 속도 계수, 경사에 따른 가감속 |
| 부스트 | 목표 속도 × 1.7, 열 +34/초 |
| 정상 냉각 | -23/초 × 차량 냉각 계수 |
| 과열 | 열 100에서 잠금, 속도 × 0.64, 열 36까지 회복 필요 |
| 과열 냉각 | -14/초 × 차량 냉각 계수 |
| 안정화 | 목표 속도 × 0.77, 횡방향 위험 × 0.35, 부스트 중단 |
| 주행선 | ±2.05 이내, 코너 주행 거리·젖은 영역 회피·추월에 영향 |
| 젖은 영역 | 횡방향 위험 × 1.55, 레일 접촉과 미끄러짐에 따른 속도 손실 |
| 횡풍 | 지정된 구간에서 점진적으로 증가·감소, 안정화로 힘 감소 |

계기판의 KM/H는 게임 속도에 10을 곱한 미니카 환산 표시이며 실제 자동차 물리 시뮬레이션 수치가 아닙니다. 차량 카드의 0–100 값은 제공된 이미지의 성향 지표이며 직접적인 km/h·초 단위가 아닙니다.

## 트랙과 시간

`TrackSampler`의 하나의 중심 곡선에서 도로·레일·차량 위치·미니맵을 생성합니다. 길이 기반 표본과 연속적인 방향 프레임을 사용합니다. 수직 루프에서 이전 방향을 평행 이동하고 폐곡선의 누적 회전을 보정하여 트랙의 위쪽 방향이 끊기지 않게 했습니다. 좌우 미끄러짐은 도로 횡방향 곡률로 계산합니다.

물리 업데이트는 1/60초입니다. 한 렌더 프레임의 반영 시간은 0.1초로 제한하며, 포커스 해제 시에는 일시정지합니다. 30·60·120Hz의 동일 입력 시뮬레이션을 테스트합니다.

## 상태와 기록

`로딩 → 차고 → 카운트다운 → 경주 → 결과 → 다시 경주 / 차고`

`경주·카운트다운·리플레이 ↔ 일시정지`, `결과 → 리플레이 → 결과`

상태 변경은 `GameState`에서 검증합니다. 재시작 시 게임 규칙 객체와 리플레이 프레임을 초기화하고, 기존 3D 모델·지오메트리·텍스처는 재사용합니다.

경주 좌표·주행선·속도·열·날씨 단계·완주 시점을 20Hz로 저장합니다. 리플레이에서는 저장한 좌표를 보간하며 본 경주를 다시 시뮬레이션하거나 결과·로컬 기록을 수정하지 않습니다. 바퀴 각도는 기록된 진행거리에서 계산합니다.

로컬 기록 키는 `tabletop-racers-v2`입니다. 저장소 접근 거부·잘못된 JSON·유효하지 않은 차량 기록을 처리합니다. 저장 실패 시 현재 세션의 결과는 계속 확인할 수 있습니다.

| `src/race/` | AI, 체크포인트·랩·순위·완주 |
| `src/core/` | 상태·고정 간격 루프·저장소 |
| `src/world/` | 작업실, 원본 이미지 배경, 소품·재질 |
| `src/replay/` | 경주 기록·보간 재생 |
| `src/ui/HUD.js` | 실제 버튼·수치·다이얼로그·미니맵 |
| `styles.css`, `theme.css` | 반응형 구조와 이미지 세트 기반 테마 |
