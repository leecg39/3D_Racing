## 성능 측정의 범위

Chrome 실제 경주에서 게임이 집계한 1초 단위 FPS 표본은 대체로 60FPS였습니다. 첫 검수의 37개 표본에서 최솟값 55, 중앙값 60, 최댓값 61을 관측했습니다. 최종 재검수의 상세 표본은 [browser-report.json](evidence/browser-report.json)에 있습니다. 모든 구간·장치의 60FPS를 보장하는 벤치마크는 아닙니다.

첫 검수에서 최대 300 draw calls, 73,616 triangles를 관측했습니다. 초기 계획의 임시 draw call 예산 150은 초과했습니다. 실제 측정 환경에서는 주행 속도가 안정적이었지만 저사양 기기에는 추가 렌더링 최적화가 필요할 수 있습니다.

처음 등장하는 카메라·물체의 GPU 업로드 후, 연속 재시작에서 geometry·texture 수가 더 증가하지 않는 것을 확인했습니다. JS 힙 프로파일링이나 수시간 장기 메모리 테스트까지 수행한 것은 아닙니다.

## 확인하지 못한 항목과 제한

- Safari 26.6.2의 드라이버를 확인했지만 `safaridriver` 실행 시 자동화 설정/인증 미완료 오류가 발생했습니다. 시스템의 Safari 자동화 설정을 변경하지 않았으며, **Safari 호환성은 미검증**입니다.
- `browse` 스킬의 기본 헤드리스 브라우저에서는 WebGL 컨텍스트 생성이 실패했습니다. 실제 설치된 Chrome의 그래픽 가속 창으로 전환해 렌더링과 주행을 검증했습니다. 소프트웨어 렌더러에서의 낮은 FPS를 실제 기기 성능으로 취급하지 않았습니다.
- 최종 재검수 중 한 번 테스트 창이 종료되어 검수가 중단됐습니다. [중단 기록](evidence/interrupted-browser-report.json)을 보존하고, 설치된 Chrome의 기본 헤드리스 모드에서 다시 검수하여 전체 항목을 통과했습니다. 최종 실행에서는 소프트웨어 렌더링을 강제하지 않았습니다. 첫 번째 전체 완주 영상도 별도 보존했습니다.
- 터치 주행·게임패드·온라인 대전·트랙 편집기·부품 교체 튜닝·점프·PIT 정비·노면 자동 부스트 패드는 구현하지 않았습니다. 관련 이미지 소품은 시각 요소입니다.
- 작은 화면에서는 UI를 재배치하고 PC 키보드 이용 안내를 표시합니다. 모바일 플레이를 지원한다고 주장하지 않습니다.
- 차량 형상은 첨부 이미지의 스타일을 반영한 코드 생성 모델입니다. 사진과 동일한 세부 품질이나 이미지 기반 3D 복원을 보장하지 않습니다.
- 일부 원본 투명 이미지에 있는 테두리·주변 조각이 카드에서 보일 수 있습니다. 외곽 정리가 된 별도 게임용 이미지로 교체하면 개선할 수 있습니다.
- 모든 자산은 로컬 번들에 포함하지만, 서비스 워커·설치형 PWA·네트워크 없이 최초 실행하는 기능은 구현하지 않았습니다.
- Three.js 배포 청크가 약 508KB여서 Vite의 500KB 경고가 남습니다. 압축 크기는 약 128KB이며 빌드 오류는 아닙니다.
