# TABLETOP RACERS

첨부된 7개 이미지 에셋을 활용한 브라우저 3D 미니카 레이싱입니다. 작업실 차고에서 차량을 선택하고, AI 3대와 수직 루프가 있는 서킷을 15바퀴 달립니다.

## 실행

Mac에서는 **`게임 실행.command`를 더블클릭**하세요. Node.js 22.12 이상이 필요합니다. 또는 프로젝트 폴더에서:

```bash
npm install
npm run dev
```

브라우저에서 <http://127.0.0.1:5173>을 엽니다. `index.html`을 파일로 직접 여는 방식은 지원하지 않습니다.

## 플레이

자동으로 전진하며, 주행선과 부스트·안정화 타이밍을 직접 선택합니다.

기본 속도는 최초 버전 대비 **150% 상향(2.5배)**, 부스트 포함 최고 속도는 **400km/h**입니다. ZEPHYR의 평지 기본 목표 속도는 177.5km/h이며 차량·경사·접지에 따라 달라집니다. 레일에 부딪히면 순간 감속, 안쪽 반동, 불꽃과 충격음이 발생합니다.

처음 접속하면 소리가 켜진 상태로 시작합니다. 이전 음소거 설정은 보존되므로 소리가 없으면 상단 **소리 켜기** 또는 설정의 **소리 확인 · 효과음 켜기**를 누르세요. 음량 0 복구와 브라우저 오디오 재개를 지원합니다. 기기·브라우저 탭 자체의 음소거는 별도로 해제해야 합니다.

| 조작 | 기능 |
|---|---|
| A / D 또는 ← / → | 좌우 주행선 이동 |
| Space | 부스트. 모터 열이 올라갑니다. |
| Shift | 안정화. 접지를 높이는 대신 속도가 줄고 부스트가 꺼집니다. |
| C / 1–6 | 카메라 전환 / 직접 선택 |
| Esc / P | 일시정지·재개 |
| 차고에서 드래그 / 휠 | 차량 회전 / 확대 |

직선에서 짧게 부스트를 쓰고, 모터를 식히며 코너를 공략하세요. 2랩의 푸른 구간은 젖은 노면이며 안쪽 일부 주행선으로 피할 수 있습니다. 3랩부터 마지막 15랩까지 비와 횡풍이 더해집니다. 모든 차량에 똑같은 속도·열·접지 규칙을 적용합니다.

## 구현 기능

- 이미지 속 ZEPHYR, VORTEX, BULLDOG, NOVA를 따라 제작한 개별 3D 차량과 주행 성향
- 차고에서 8개 부품 선택·강조, 분해·조립, 바퀴 회전 테스트
- 원본 차량 이미지를 사용하는 선택 카드, 7개 에셋 원본을 확인하는 도감
- 커팅 매트, 공구, 모니터, 선풍기, 작업실 이미지 배경을 조합한 3D 공간
- 실제로 통과하는 수직 루프, 경사, 고가, 커브, 레일과 순서가 있는 체크포인트
- AI 3대와 15랩 경주, 부스트·과열·안정화·주행선, 코너와 앞차를 고려한 AI
- 건조 → 젖은 구간 → 비·횡풍의 날씨 변화
- 추격·전체·전방·롤러·트랙사이드·자동 감독 카메라
- 순위·랩·시간·속도·열·접지·미니맵 HUD
- 완주 결과·랩별 기록·재시작·이 브라우저의 상위 10개 기록
- 실제 경주 좌표를 기록하는 리플레이, 탐색 막대, 0.5/1/2배속
- 효과음 켜기·음량, 성능 모드, 카메라 움직임 감소
- 포커스 해제 자동 일시정지, 입력 초기화, WebGL·에셋 로딩 오류 안내

## 검증 및 빌드

```bash
npm test              # 게임 규칙·리플레이·저장소·10회 완주 시뮬레이션
npm run test:browser  # 실제 설치된 Google Chrome에서 조작·완주·리플레이 검증
npm run build        # dist/에 배포 파일 생성
npm run preview      # 빌드 결과 미리 보기
```

브라우저 테스트는 개발 서버가 실행 중이어야 합니다. 화면 녹화·캡처·JSON 보고서는 `docs/evidence/`에 생성합니다. 이 테스트는 별도 Chrome 창을 열며 개인 프로필을 사용하지 않습니다.

창을 표시하지 않고 검증하려면 `HEADLESS=1 npm run test:browser`를 사용합니다. 빌드 서버 실행 후 `node tests/smoke.mjs`로 외부 의존성 없는 실행과 오류 처리를 확인할 수 있습니다.

배포할 때는 `dist/` 전체를 정적 호스팅에 올립니다. JavaScript·폰트·이미지가 빌드에 포함되므로 실행 중 외부 CDN을 요구하지 않습니다. 서비스 워커나 설치형 오프라인 앱은 구현하지 않았습니다.
